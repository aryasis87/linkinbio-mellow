# Mella — Ilustrator & Sticker Artist

Link in bio ilustrator & sticker artist Mella: semua karya lucu dan menggemaskan dalam satu tempat.

**Demo live:** https://linkinbio-mellow.vercel.app

![Tangkapan layar Mella](public/og.jpg)

> Template link-in-bio dengan persona fiktif.

## Konsep

Persona Mella, ilustrator dan pembuat stiker. Papan stiker pastel: tautan berbentuk stiker miring bertepi putih, avatar kelinci, dan hover yang memantul.

## Halaman

`/`

## Teknologi

- Next.js 15.5 (App Router) dan React 19
- Tailwind CSS v4
- JavaScript
- Lucide (ikon)
- Font: Quicksand (next/font)
- SEO: metadata per halaman, Open Graph, JSON-LD, sitemap.xml, dan robots.txt

## Menjalankan secara lokal

```bash
npm install
npm run dev
```

Buka http://localhost:3000. Untuk build produksi: `npm run build` lalu `npm start`.
